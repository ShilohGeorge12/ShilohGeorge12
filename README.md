# Shiloh George: full-stack developer for SME operations

I turn the operational headaches of running an SME (bookings, quotes, inventory, follow-ups) into web tools that quietly run themselves. Fully remote since December 2024, shipping production work for distributed teams: async by default, self-directed by design.

## What I build

- Web apps end to end: Figma design to deployed product, frontend to API to database.
- Frontends that feel right: pixel-accurate from the spec, fast and findable. Core Web Vitals are features, not afterthoughts.
- Backends that hold up: REST APIs in Node, Express, and NestJS, data model designed before the routes.
- Integrations with stakes: payments, KYC, tax engines. Code that survives real transactions and real regulations.
- The specialty underneath it all: SME ops. If it lives in a spreadsheet, it can live in a web app.
